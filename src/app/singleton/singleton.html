Single Page Application

One page. Multiple views. No full reload.

A Single Page Application updates parts of the screen without reloading the entire webpage.

01 · How it works

How does an SPA work?

Only the content you need changes. The rest stays in place.

    Loaded once. Stays on screen.

  • Dynamic

    Replaced on every navigation.

  • One HTML page

    Downloaded only once.
