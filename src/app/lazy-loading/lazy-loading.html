Core concept · Performance

Lazy Loading

Load only what you need, when you need it.

Lazy Loading delays downloading certain parts of an application until they are needed.

01 · Compare

Eager vs Lazy

Same website. A different first download.

Eager Loading

  1. The user opens the website.
  2. All three bundles download immediately.
  3. Unvisited pages are included.

👤 Opens the website ↓

  • Home.js
  • About.js
  • Dashboard.js

Download everything upfront.

Lazy Loading

  1. The user opens the website.
  2. Only the needed code downloads.
  3. Other bundles stay unloaded.
  4. Opening Dashboard downloads its bundle.

👤 Opens the website ↓ 👆 Opens Dashboard

  • Home.js
  • About.js · not loaded
  • Dashboard.js

Download code when it is needed.
